# Автоняня Челны — мобильное приложение (MVP)

Один код → Android (RuStore, Google Play) и iOS (App Store).
Стек: **Expo / React Native** + **Supabase** (база данных, вход по СМС, хранилище фото).

## Что умеет

**Родитель**
- вход по номеру телефона с кодом из СМС;
- выбирает районы города, где нужны поездки;
- создаёт профили детей: имя, возраст, школа/секция, класс, откуда → куда (районы), расписание, особенности здоровья (видны только родителю);
- видит **только проверенных** автонянь, работающих в его районах, и звонит / пишет в WhatsApp.

**Автоняня**
- вход по телефону (номер подтверждается СМС);
- анкета: ФИО, дата рождения (от 21 года), опыт, цена, авто (марка, цвет, госномер, детское кресло);
- выбирает районы, где готова работать;
- **паспорт обязателен**: серия и номер + фото разворота + селфи с паспортом (только с камеры);
- пока анкета на проверке — никто её не видит; после одобрения видит запросы родителей в своих районах.

**Модератор (вы)**
- экран «Проверка автонянь»: фото паспорта, селфи, данные; кнопки «Одобрить» / «Отклонить с причиной».

**Безопасность**
- паспортные данные и фото — в приватном хранилище, их видит только сама автоняня и модератор;
- автоняня не может сама себя одобрить (защищено на уровне базы);
- при замене паспорта/фото анкета снова уходит на проверку;
- один паспорт = одна анкета;
- телефон в профиле берётся только из подтверждённого СМС-входа;
- удаление аккаунта из приложения (требование App Store и Google Play).

Районы города редактируются в `src/lib/districts.ts`.

## Запуск

1. Создайте проект на [supabase.com](https://supabase.com) (или поднимите Supabase на российском сервере — см. «Закон о персональных данных»).
2. SQL Editor → вставьте `supabase/schema.sql` → Run.
3. СМС: Authentication → Sign In / Providers → Phone → включить.
   Для доставки в РФ подключите SMS.ru через функцию `supabase/functions/send-sms` (инструкция в начале файла).
   Для тестов можно добавить тестовые номера с фиксированным кодом (Phone → Test phone numbers).
4. `cp .env.example .env` и вставьте URL и anon key проекта (Project Settings → API).
5. `npm install` → `npx expo start` → откройте в приложении Expo Go или development build.
6. Назначьте себя модератором — SQL в конце `schema.sql`.

## Сборка и публикация

```bash
npm i -g eas-cli && eas login
eas build -p android --profile rustore      # APK для RuStore
eas build -p android --profile production   # AAB для Google Play
eas build -p ios --profile production       # для App Store (нужен Apple Developer)
```

Перед публикацией: замените иконки в `assets/`, разместите политику конфиденциальности
и согласие на обработку ПДн на сайте (ссылка обязательна во всех сторах).

## Закон о персональных данных (152-ФЗ) — важно

- Паспортные данные граждан РФ должны храниться **на серверах в России**.
  Для продакшена: Supabase self-hosted на Yandex Cloud / Selectel / VK Cloud, либо российский облачный Postgres.
- Нужно уведомить Роскомнадзор об обработке ПДн (pd.rkn.gov.ru) — делается онлайн, бесплатно.
- Согласие на обработку ПДн собирается в анкете (галочка), дата сохраняется в `pd_consent_at`.
- После одобрения анкеты фото паспорта можно удалять — данные сверены, хранить копии не обязательно.
